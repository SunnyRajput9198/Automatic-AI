1. Wikipedia — React (software)

2. ArXiv — Developing a 21st Century Global Library for Mathematics Research
   Developing a 21st Century Global Library for Mathematics Research discusses how information about what the mathematical literature contains can be formalized and made easier to express, encode, and explore. Many of the tools necessary to make this information system a reality will require much more than indexing and will instead depend on community input paired with machine learning, where mathematicians' expertise can fill the gaps of automatization.
   URL: http://arxiv.org/abs/1404.1905v1

3. ArXiv — Semantics and Security Issues in JavaScript
   There is a plethora of research articles describing the deep semantics of JavaScript. Nevertheless, such articles are often difficult to grasp for readers not familiar with formal semantics. This report proposes a digest of the semantics of JavaScript centered around security concerns and provides an overview of the JavaScript language and the misleading semantic points in its design.
   URL: http://arxiv.org/abs/1212.2341v1

4. ArXiv — On the road to percent accuracy IV: ReACT -- computing the non-linear power spectrum beyond ΛCDM
   To effectively exploit large-scale structure surveys, we depend on accurate and reliable predictions of non-linear cosmological structure formation. The public software package ReACT demonstrates its capability for the fast and accurate calculation of non-linear power spectra from non-standard physics.
   URL: http://arxiv.org/abs/2005.12184v2
