1. Wikipedia — Learning curve (machine learning)
   In machine learning (ML), a learning curve is a graphical representation that shows how a model's performance on a training set changes with the number of training iterations (epochs) or the amount of training data.
   Typically, the number of training epochs or training set size is plotted on the x-axis, and the value of the loss function on the y-axis.
